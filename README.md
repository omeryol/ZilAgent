# ZilAgent

ZilAgent is an offline-first Android app for school bell schedules, lesson flow tracking, and countdown widgets.

## Features

- Offline by design: no internet permission, local-only data
- Flexible bell schedule engine with profile support
- Two practical widgets:
  - Live Countdown
  - Lesson Flow
- Exam mode with large fullscreen timer
- Turkish and English UI support
- Local backup/restore and QR profile transfer

## F-Droid

This project is FOSS (GPL-3.0-or-later) and designed to work fully offline.
Fastlane metadata is included under `fastlane/metadata/android/`.
F-Droid build metadata template is included at `metadata/com.zilagent.app.yml`.
